## Features *currently* in the demo game that the game engine needs to support

- starting map objects
  - tree
  - campfire
  - techbro
    - press space to talk
    - can choose your name
    - remembers your name
    - knows how many clouds you have
    - can edit your max health
  - typescript altar
- tiles [demo could be simplier]
  - grass, dirt, bad_wall, black void
  - with tile texutre blending
- player can shoot meatballs
  - explode after some time
  - deal damage
  - clear paint lines
  - knocks entities back
  - player can run out of meatballs
- player can paint lines that turn green after a while
- camera shake triggered by meatball explosions
- particles triggered by knife attacks
- spawns enemies
- player can attack entities with knives
  - which also knocks entities back
- health bars
- debug collider view
- tile editor
- player can plant seeds
  - player gets seeds over time
- player plays footstep sounds when walking
- interact with corpses to receive cloud item
- colliding with d20 pushes it around
- enemy follows player within certain distance
- explosion is deleted after some time
- meatball bounces while moving
- player can teleport
